3. Inspect an acceleration reading

Magnitude is √(x² + y² + z²), using the exported acceleration values. No gravity correction is applied. The red line marks the selected reading. Long traces use a minimum/maximum envelope to preserve visible peaks.

4. Screen for suspected road events

The rule calculates RMS acceleration magnitude in half-second windows. Automatic mode flags windows above the recording's median RMS plus six scaled median absolute deviations, with a minimum margin of 0.5 m/s². Adjacent flagged windows are merged into one candidate. This rule has not been validated against pothole labels.
